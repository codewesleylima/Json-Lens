FEIGN · ORIGEM DE VALORES
O plugin busca atribuições diretas e setters antes da chamada Feign. Teste diferentes evidências estáticas no laboratório.


LIMITAÇÕES IMPORTANTES
PSI depende de Java indexado e documento válido; edição incompleta pode atrasar a atualização.
Não verifica toda a cadeia Controller → Service → Mapper → HTTP.
Sem análise equivalente de RestTemplate, WebClient, Java HttpClient, Kotlin, Protobuf, Avro ou GraphQL.
Serialização customizada, tipos dinâmicos, referências externas e branches oneOf/anyOf podem ser incompletos.


05 / VALIDATION LAB


Matriz de cobertura.
Checklist interativo para revisar a experiência antes de levar o design ao plugin IntelliJ. Simulado é uma demonstração guiada, não análise real de PSI Java.


O HTML permite testar navegação, importações locais, parsing de formatos comuns, comparações demonstrativas e feedback. A leitura de projetos Java, indexação PSI, resolução de referências Java e integração com a IDE exigem a implementação nativa.






Privacidade neste HTML: não há chamadas de API, serviços de IA ou envio de arquivos. Os arquivos selecionados são processados no próprio navegador. As preferências são guardadas apenas no armazenamento local do navegador.
